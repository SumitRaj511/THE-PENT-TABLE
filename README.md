# THE PENT TABLE

A responsive food delivery frontend built with HTML, CSS and vanilla JavaScript.

## Run locally
Extract this folder, open a terminal inside it, and run:

```bash
python -m http.server 8000
```

Open http://localhost:8000 in your browser. Alternatively, use VS Code Live Server.
No npm install or build step is required.

## Files
- index.html: page structure
- style.css and feature.css: styling and animations
- app.js: restaurant menus, search, filters, cart, demo checkout and scroll effects
- assets/: images, fonts and dough-making video

## Deployment
Upload this folder as a static site. On Vercel, choose Other as the framework; no build command is needed.

## Notes
This is a frontend demonstration. Orders are stored in the browser; no backend, real payments or delivery fulfillment is connected.
Video attribution is included in assets/pizza-dough-source.txt.

Live website: https://the-pent-table.vercel.app
